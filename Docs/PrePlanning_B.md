## 01. 게임 개요

빛과 그림자를 이용해 밤꽃을 깨우는 공간 퍼즐 어드벤처.

### 1.1 소개

태양등의 빛을 이어 다음 등을 점화하고, 기둥에 생긴 그림자 길로 단절된 공간을 건너 **세 정원**의 밤꽃을 깨운다.

### 1.2 플레이 방향

설명문보다 조작과 세계 반응을 먼저 보여준다. 빛·그림자·문·꽃은 조작 직후 상태를 바꾸며, 정답과 목적을 세계 안의 반응으로 전달한다.

### 1.3 구성 방향

| 구분 | 내용 |
| --- | --- |
| 플레이 우선 | 이동, 회전, 그림자 변화가 먼저 이해되어야 한다 |
| 즉시성 | 입력과 빔, 그림자, 충전, 문 상태가 지연 없이 연결 |
| 단순한 입력 | WASD, Q/E, SPACE, R만 · 월드가 바뀌어도 새 버튼 없음 |
| 공용 시스템 | 차이는 배치·거리·높이·중첩·**판단 스텝 수**로 만든다 |
| 완결 길이 | **한 사이클 32~48분** 안에 세 지역 회복과 엔딩 |
| 비전투 | 적·체력·무기 없음 |

### 1.4 목표 경험

‘내가 공간의 원인을 읽고 정원을 직접 복구했다’는 손맛. 각 X-5에서는 퍼즐 해답이 지역색·식생·환경음 회복으로 번역된다.

## 02. 게임 플레이

### 2.1 규칙

- 방에는 하나의 기본 활성 태양등이 주어진다.
- 비활성 태양등은 활성 태양등의 빛을 받았을 때만 점화된다.
- 선택한 태양등의 영향 범위는 **방향 부채꼴 + 최대거리 원**으로 표시한다.
- 서로 다른 활성 범위가 같은 기둥을 덮으면 범위마다 **독립된 그림자**가 생긴다.
- 다중 그림자는 간섭 상태이며, 플레이어는 **SPACE**로 선택한 활성 태양등 하나를 끈다.
- 간섭이 해소되면 하나의 안정된 그림자가 낭떠러지를 건너는 길이 된다.
- 해받이가 빛을 머금으면 문이 열리고, X-5에서는 밤꽃 개화까지 이어진다.

### 2.2 코어 루프

1. 단절 지형, 기본 활성등, 비활성등, 기둥, 해받이 위치를 살핀다.
2. Q/E로 기본 활성등을 연속 회전시켜 다음 태양등에 빛을 맞춘다.
3. 새로 켜진 태양등과 기존 범위가 만든 그림자 중첩·간섭을 읽는다.
4. SPACE로 선택한 활성 태양등 하나를 꺼 단일 그림자 길을 확정한다.
5. 그림자 길을 건너 해받이를 충전하고 문을 연다.
6. X-5에서는 익힌 릴레이를 조합해 지역의 밤꽃을 피운다.

### 2.3 방·스테이지 완료와 시간

- 각 스테이지 = 하나의 방.
- 일반 방: 점화 → 간섭 해소 → 그림자 횡단 → 해받이 충전 → 문 개방.
- X-5: 위와 동일 + **밤꽃 개화** (W3-5는 모체 개화 + 엔딩 시퀀스).
- **목표 체감 시간: 방당 2~3분.**
- 밀도 규칙: 새 시스템 없이 **판단 스텝 2~4회**(릴레이/회전/OFF) + 횡단·해받이 1회.
- 맵만 키우고 스텝을 늘리지 않는 팽창은 금지.
- 온보딩(1-1만): **10초 안에 영향 범위 확인 / 30초 안에 다음 태양등 점화**.

### 2.4 조작

| 입력 | 기능 | 손맛·제약 |
| --- | --- | --- |
| WASD | 자유 8방향 이동 | 즉시 반응 · 격자·타일 스냅 없음 |
| Q / E | 선택 태양등 연속 회전 | 짧게 정밀 · 길게 가속 · 놓으면 짧은 감속 |
| SPACE | 선택 활성 태양등 OFF | ON 기능 없음 · 간섭 해소와 엔딩에 사용 |
| R | 현재 방 초기화 | 사망·체력 패널티 없음 |

회전: 최대 속도 캡, 정답 각도 ±3° 약한 자석 보정 + 클릭음. 빔·그림자는 매 프레임 갱신.

### 2.5 UI·피드백

상시 HUD 최소화. 선택·조작 시에만 영향 범위와 상태를 명확히 표시.

| 대상 | 표현 | 의미 |
| --- | --- | --- |
| 영향 범위 | 방향 부채꼴 + 최대거리 원 | 빛이 닿을 수 있는 영역 |
| 활성등 | 금색·민트·청록 범위색 | 활성 범위 구분 |
| 비활성등 | 수신 고리 점화 진행 | 곧 켜지는 상태 |
| 다중 그림자 | 주황 경고·중첩 강조 | 간섭 |
| 해받이 | 충전색·단계별 음정 상승 | 문 개방 진행 |
| 문·밤꽃 | 큰 상태 변화·완료음 | 방/월드 완료 |

## 03. 오브젝트와 상태

### 3.1 공용 오브젝트

| 오브젝트 | 기능 | 상태 |
| --- | --- | --- |
| 태양등 | 저장·연속 회전·릴레이 점화·선택 OFF | Inactive / Receiving / Active / OFF |
| 기둥 | 활성 범위마다 그림자 생성 | 낮음·중간·높음 |

| 밤꽃 | 과잉 빛을 밤빛·씨앗으로 전환 | Dormant / Blooming / Bloomed · X-5 |

### 3.2 상태 전이

| 대상 | 전이 | 증거 |
| --- | --- | --- |
| SunLamp | Inactive → Receiving → Active → OFF | 범위 UI · 점화 고리 · 간섭 · 소등 |
| NightFlower | Dormant → Blooming → Bloomed | 꽃잎 · 광량 · 파티클 |
| Region | Unrestored → Restored | 식생 · 색 · 환경음 |
| Door | Closed → Opening → Open | 해받이 · 문 애니 |

### 3.3 처리 규칙

- 다른 활성등의 빛으로만 Inactive → Receiving.
- SPACE는 선택한 Active만 OFF.
- 한 기둥이 N개 Active 범위에 있으면 그림자 N개.
- R은 해당 방의 태양등·해받이·문·그림자를 진입 상태로 복구.
- 문·밤꽃 상태가 서사 진행을 겸함 (퀘스트 로그 없음).

## 04. 세계관과 월드 진행 (B안)

### 4.1 세계관

빛이 넘친 날, 오래된 빛 조절 장치가 멈추며 정원의 길과 **세 송이 밤꽃**이 잠들었다. 원인은 악당이 아니라 고장 난 순환이다. 목표는 빛을 없애는 것이 아니라 **제자리를 찾아주는 것**이다.

### 4.2 모아

정원 수습생. 대사 없음. 무기·공격·체력 없음. 자유 이동과 정원 장치만 사용. 엔딩의 마지막 태양등도 직접 끄고 퇴장한다.

### 4.3 월드·스테이지 구조 (잠금)

| 월드 | 지역 | 스테이지 | 1~4 학습·조합 | X-5 피날레 |
| --- | --- | --- | --- | --- |
| 1 | 노을 과수원 | 1-1~1-5 | 기본 활성등 · 범위 UI · 낮음/중간 기둥 · 첫 릴레이 | 첫 밤꽃 개화 |
| 2 | 바람종 협곡 | 2-1~2-5 | 높은 기둥 · 다중 그림자 · SPACE OFF · **후반 세 등 릴레이** | 둘째 밤꽃 개화 |
| 3 | 별뿌리 온실 | 3-1~3-5 | **초반 세 등 릴레이** · 중앙 범위 집중 · 최종 릴레이 | 모체 밤꽃 + 엔딩 |

**삭제·흡수**

- **물거울 습지원**: 본편 제외.
- 습지원이 담당하던 세 등 릴레이·순서 판단 → **2-4~2-5 및 3-1~3-2**에 흡수.
- 새 버튼 추가 금지. 깊이 = 거리·기둥 높이·태양등 수·범위 중첩·해받이 배치·**스텝 수**.

### 4.4 WORLD 1 · 노을 과수원

마른 수로와 빛바랜 과수원. 1-1~1-3은 이동·범위·점화·횡단 온보딩(1-1만 10초/30초). 1-4는 릴레이 심화, **1-5**에서 첫 밤꽃.

- 환경 전: 마른 수로, 빛바랜 잎, 멈춘 해받이
- X-5 결과: 지역색 회복, 잎·수로 환경음, 첫 빛이 중앙으로

### 4.5 WORLD 2 · 바람종 협곡

바람종이 멈춘 협곡. 초반에 두 범위 간섭과 SPACE OFF를 가르치고, **후반에 세 등 릴레이·순서 선택**을 추가한다.

- 환경 전: 멈춘 바람종, 끊긴 목교, 먼 사암 발판
- 학습: 높은 기둥·긴 그림자·다중 그림자 → 세 등 점화 순서
- X-5 결과: 바람종 재가동, 둘째 빛이 중앙으로

### 4.6 WORLD 3 · 별뿌리 온실

앞선 두 지역의 빛이 온실 뿌리에 도착한 상태. 초반에 세 등 릴레이를 재확인하고, 후반에 범위를 모체 밤에 집중한다. **3-5**에서 모체 개화와 엔딩.

- 길을 만들 때: 단일 그림자
- 개화할 때: 여러 빛 집중 (같은 범위 규칙의 피날레)
- 결과: 모체 개화, 세 번째 빛 완성, 씨앗빛이 전 지역으로

### 4.7 환경 서사

| 지역 | 회복을 보여주는 요소 |
| --- | --- |
| 과수원 | 잎, 수로, 과수 |
| 협곡 | 바람종, 목교, 먼 발판 |
| 온실 | 뿌리, 유리, 야광 식생 |

설명을 읽는 대신, 자신이 바꾼 공간을 다시 바라본다.

## 05. 연출 디렉팅

### 5.1 오프닝

세 문장 → 장면 → Q/E 회전. 설명창·성우·외부 매뉴얼 없음.

> “정오가 멈추자, 정원은 스스로를 가두었다. 한 아이가 빛을 되돌리러 왔다. 첫 태양등의 빛을 이어, 밤꽃을 하나씩 깨워라.”

### 5.2 X-5 지역 회복 (4–6초)

| 순서 | 길이 | 연출 |
| --- | --- | --- |
| 1 | ~2초 | 밤꽃 꽃잎·빛·파티클 |
| 2 | ~2초 | 지역 식생·색·환경음 |
| 3 | 잔여 | 씨앗빛이 중앙으로 · 다음 문 개방 |

카메라 팬 1회 이내 · 캐릭터 연기 없음 · 틀 공용, 지역 색·효과음만 변경.

### 5.3 엔딩 (20–30초)

**세 빛**이 모체 밤꽃에 모이고, 씨앗빛이 **세 지역**으로 돌아간다. 밤은 밤으로 남는다.

1. 개화 후 조작권 복귀
2. SPACE로 마지막 활성 태양등 OFF
3. 문 개방 → 모아 직접 퇴장
4. 짧은 페이드 + 로고

### 5.4 수미상관

| 시작 | 엔딩 |
| --- | --- |
| 넘쳐버린 낮의 빛 | 제자리를 찾은 밤의 빛 |
| 닫힌 세 송이 밤꽃 | 피어난 세 송이 밤꽃 |
| 사라진 그림자 길 | 돌아온 그림자 길 |
| 닫힌 마지막 문 | 열린 마지막 문 |
| 첫 입력: Q/E로 빛 잇기 | 마지막 입력: SPACE로 빛 내려놓기 |
| 미완성 음악 모티프 | 같은 모티프 완성 + 짧은 정적 |

## 06. 아트·사운드

### 6.1 시점·공간

엄격한 탑뷰. 격자·타일 스냅 없음. 기둥 높이·낭떠러지 깊이를 명암으로 읽히게. 그림자 길은 지형보다 높은 명도 대비. 장치는 전 지역 동일 실루엣·금속 테두리.
