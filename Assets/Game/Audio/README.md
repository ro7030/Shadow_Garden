# Shadow Garden original audio

All clips in this folder are original deterministic synthesis created for **Shadow Garden** on 2026-08-05.
No third-party recordings or music samples are used.

- Generator: `Tools/GenerateShadowGardenAudio.py`
- Source WAV masters: `Assets/Game/Art/Source/Audio`
- Runtime music and ambience: lossless WAV masters imported by Unity as Vorbis
- Runtime short effects: 44.1 kHz stereo WAV
- Intended defaults: BGM 70%, SFX 80%

The music uses a small brass-chime motif, slow garden-air oscillators, and distinct harmonic colors for the orchard, canyon, and greenhouse. Effects are synchronized to the documented presentation timings.
