## 3. 팀 역할

### 인간 관리자

- 메인 기획자, 최종 관리자, 플레이 QA
- 게임 방향, 손맛, 아트와 사운드의 최종 선택
- Git commit, push, main 반영의 최종 승인
- Codex 검수를 통과한 빌드를 직접 플레이하고 승인 또는 반려

### Codex

- 서브 기획자와 중간 관리자
- 검토 개발자, 검토 디자이너, 검토 사운드 디자이너, 서브 QA
- 기획 요구사항을 작은 작업 브리프로 변환
- Cursor 작업 지시, 실제 파일·Git diff·Unity·테스트·화면·사운드 검수
- 작은 결함 직접 수정 또는 재작업 지시
- 인간 관리자 승인 전 commit, push, merge 금지

### Cursor Grok 4.5

- 팀원급 프로그래머, 디자이너, 사운드 디자이너
- 승인된 브리프의 범위 안에서 코드와 에셋 구현
- 한 번에 하나의 시스템 묶음만 작업하고 보고 후 정지
- 독자적인 기획, API, 패키지, ProjectSettings 변경 금지
- commit, push, merge 금지
- 실제 산출물과 검증 증거가 없으면 완료 선언 금지

### Gemini

- BGM, 영상 등 분리 가능한 외주 작업
- 저장소 접근 금지
- Codex가 브리프와 검수표를 만들고 인간 관리자가 전달
- 결과는 기획서 폴더의 외주 산출물 영역에서 검수한 뒤 승인 파일만 Unity에 반입

## 4. 게임 제작 불변 조건

- 비전투 3D 탑뷰 공간 퍼즐이며 Unity XZ 평면과 고정 직교 카메라를 사용한다.
- WASD 이동, Q/E 태양등 회전, SPACE 선택 Active OFF, R 방 초기화, ESC Pause를 사용한다.
- 권위 빛 판정은 부채꼴, 거리, `LightObstacle` 시야선 센서다. URP Light는 분위기만 담당한다.
- 태양등은 `Inactive → Receiving → Active → Off` 상태를 사용한다.
- Active는 원본 빛이 끊겨도 유지되고 Off는 회전·재점화 가능하다.
- 마지막 Active 소등은 일반 플레이에서 차단하고 엔딩에서만 허용한다.
- 회전 중 그림자 시각 메시는 갱신하지만 보행 콜라이더는 끈다. 0.15초 안정 후 단일 그림자만 통행 가능하다.
- 다중 광원 그림자는 모두 보이지만 간섭 상태로 통행할 수 없다.
- 추락은 최근 안전 발판으로 복귀하며 퍼즐은 유지한다. R만 방 진입 상태를 복원한다.
- 런타임 상태를 ScriptableObject에 저장하지 않는다.
- Bootstrap은 지속되고 Title, Hub, Room, Ending 중 하나만 Additive로 로드한다.
- 공식 플랫폼은 데스크톱 WebGL, 16:9, 키보드다.

## 5. 작업 생명주기

1. Codex가 작업 ID와 요구사항 ID가 포함된 브리프를 발행한다.
2. Cursor는 범위, 금지 사항, 예상 파일을 먼저 요약한다.
3. Cursor는 허용된 범위만 구현한다.
4. Cursor는 변경 파일, 구현 요구사항, 테스트 결과, 스크린샷·로그와 잔여 위험을 보고하고 정지한다.
5. Codex는 파일 존재, Git diff, Unity 컴파일, Console, 테스트와 실제 화면을 검증한다.
6. 결함이 있으면 Codex가 수정하거나 Cursor에 재작업을 지시한다.
7. Codex 검수 후 인간 관리자가 플레이 QA를 수행한다.
8. 인간 관리자가 승인한 뒤에만 직접 commit하거나 별도 commit을 요청한다.

## 6. 완료 정의

코드 작업은 다음을 모두 만족해야 한다.

- 브리프의 요구사항 ID가 구현되어 있다.
- 실제 파일이 저장소에 존재하고 Unity가 임포트한다.
- Unity Console Error 0건이다.
- 지정된 EditMode·PlayMode 테스트가 통과한다.
- 관련 Scene 또는 Sandbox에서 재현 가능하다.
- 기획 외 변경과 미보고 파일이 없다.

3D·시각·사운드 작업은 다음을 추가로 만족해야 한다.

- 원본과 내보낸 파일의 경로가 보고되어 있다.
- Unity 임포트 설정과 실제 사용 프리팹 또는 AudioClip이 존재한다.
- 3D는 Y-up, 1 unit = 1m, 루트 회전 `(0, 0, 0)`, 바닥 원점을 확인한다.
- 시각 에셋은 Game View 캡처로 형태, 명도, 카메라 가독성을 확인한다.
- 사운드는 길이, 샘플 포맷, 루프, 피크와 실제 재생 결과를 확인한다.
- 외주·생성 에셋은 출처와 사용 조건을 기록한다.

## 7. Git 및 안전 규칙

- 인간 관리자 승인 전 `git commit`, `git push`, `git merge`를 실행하지 않는다.
- 사용자 변경을 덮어쓰거나 reset, checkout, clean으로 제거하지 않는다.
- 패키지, ProjectSettings, 기획서는 브리프가 명시한 경우에만 변경한다.
- 영구 삭제, 외부 업로드, 로그인, 자격 증명, 보안 권한 변경은 실행 시점에 인간 관리자 확인을 받는다.
