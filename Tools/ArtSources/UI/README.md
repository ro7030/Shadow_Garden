# Shadow Garden UI masters

`ShadowGardenUiMaster.svg` is the editable vector source for the final panel, button, focus, world-card, node, key-cap, channel, and danger-state visual language.

- Runtime Korean copy is always rendered by TextMeshPro; text is never baked into these images.
- The master uses the production navy, ivory, mint, brass, burgundy, and coral palette.
- Unity receives inspected PNG/9-slice exports only. The SVG remains outside `Assets` so it cannot introduce an SVG package dependency.
- Focus and danger states use outline and shape differences in addition to color.
